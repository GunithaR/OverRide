# Evidence

One folder per member. Save proof for the optimization and viva criteria here, named with the date:

`YYYY-MM-DD_<topic>_<before|after>.png`, e.g. `2026-10-16_physics-collision-matrix_after.png`

- Screenshots of Profiler graphs, Stats window, Frame Debugger, collision matrix, wireframes, UV layouts.
- A short note (`.md`) next to each pair explaining what changed and the result.
- Do **not** commit raw Profiler `.data` captures or video footage (ignored by `.gitignore`); keep those
  on the shared drive and link them from the note.
